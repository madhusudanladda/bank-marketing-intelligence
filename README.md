# Bank Marketing Intelligence

An end-to-end machine-learning application that estimates the likelihood that a bank marketing contact will subscribe to a term deposit. It combines a scikit-learn training pipeline, a Streamlit dashboard, and a FastAPI inference service.

> **Dataset note:** This project uses the UCI Bank Marketing dataset (dataset ID 222) through a locally cached CSV. The `duration` feature is excluded because it is only known after a call and would leak information into a pre-call prediction. The loader normalizes the numeric day-of-month column name across source variants.

## Features

- Automated local dataset loading and caching.
- Preprocessing with `ColumnTransformer`, `StandardScaler`, and `OneHotEncoder`.
- Stratified train/test split and five-fold stratified cross-validation.
- Comparison of Logistic Regression, Random Forest, and HistGradientBoosting.
- Champion selection using mean cross-validation ROC-AUC.
- Holdout evaluation with ROC-AUC, average precision (PR-AUC), classification report, and confusion matrix.
- Serialized model pipeline and JSON metrics output.
- Streamlit dashboard for model performance, single-customer scoring, and batch CSV predictions.
- FastAPI endpoints for health checks and prediction requests.
- Pytest tests for model loading, inference, and API behavior.

## Quickstart (Windows PowerShell)

### 1. Get the project and create an environment

```powershell
git clone https://github.com/<your-username>/bank-marketing-intelligence.git
cd bank-marketing-intelligence

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks environment activation, use Command Prompt and run:

```bat
.venv\Scripts\activate.bat
```

### 2. Train the model

The serialized `.joblib` model is intentionally excluded from Git. Generate it locally before starting the dashboard or API:

```powershell
$env:PYTHONPATH = "."
python -m src.train
```

Training writes `artifacts/best_model.joblib` and `artifacts/metrics.json`. The data loader uses its local cached dataset when available; otherwise it attempts to fetch the dataset through `ucimlrepo`, which requires an internet connection.

### 3. Run the tests

```powershell
pytest -q
```

### 4. Start the Streamlit dashboard

```powershell
streamlit run streamlit_app/app.py
```

Streamlit prints the local URL (typically `http://localhost:8501`).

### 5. Start the FastAPI service

Open another activated terminal in the project folder:

```powershell
$env:PYTHONPATH = "."
uvicorn app.api:app --reload --port 8000
```

- API root: `http://127.0.0.1:8000/`
- Health check: `http://127.0.0.1:8000/health`
- Interactive API documentation: `http://127.0.0.1:8000/docs`

Example request to `POST /predict`:

```json
[
  {
    "age": 35,
    "job": "admin.",
    "marital": "married",
    "education": "tertiary",
    "default": "no",
    "balance": 1500,
    "housing": "no",
    "loan": "no",
    "contact": "cellular",
    "day_of_week": 15,
    "month": "may",
    "campaign": 1,
    "pdays": -1,
    "previous": 0,
    "poutcome": "unknown"
  }
]
```

Optional query parameter: `threshold`, for example `/predict?threshold=0.35`.

## Git hygiene

The `.gitignore` excludes virtual environments, Python caches, raw dataset files, logs, and generated `.joblib` model files. These can be recreated locally by following the training instructions. The metrics JSON is retained as a small reference report.

Before committing, inspect the staged files:

```powershell
git status --short
git add .
git status
```

Confirm that no raw CSV, `.joblib`, cache directory, credentials, or local environment files are staged.

## Limitations and responsible use

- This is a portfolio and demonstration project, not a validated banking decision system.
- Predictions are estimates and should not be treated as calibrated probabilities without a separate calibration evaluation.
- Evaluate precision/recall trade-offs and threshold selection against the campaign's actual costs before operational use.
- Do not upload personal or confidential customer data to a public demo.
